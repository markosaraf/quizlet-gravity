# App-review notes

No login, payment, invitation or special account is required. The app opens the live interactive study game at https://www.quizletgravity.com/ in a restricted native web view. External links open in the system browser.

For a deterministic review that does not depend on a third-party public set:
1. Open the app with an internet connection.
2. Choose **Create set**, then **Write your own**.
3. Enter two or more tab-separated term/definition pairs, for example:

```text
cat	Katze
dog	Hund
house	Haus
water	Wasser
```

4. Review the editable card table, follow the on-screen controls to start, and type the requested answers during the game.
5. The public-set importer and CSV/TSV file picker are additional ways to supply learning material.

The native launch carousel settles on the supplied gold/indigo logo, holds for one second and fades into the game. It has no loading spinner. A network failure shows a retry screen. Local custom games use website storage. Shared sets and leaderboard scores are stored on the server. For shared play, choose a guest username or sign in. Email/password registration requires email verification. Google sign-in uses a system authentication session and returns to the app.
